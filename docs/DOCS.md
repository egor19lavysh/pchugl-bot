## Система фильтрации по требованиям (Гидра, Химера, ЛКВ)

### Важный нюанс: Значение 2

При использовании кнопки **"От 1B"** сохраняется значение **2** в БД (поле `requirements_hydra`, `requirements_himera` или `requirements_lkv`).

**Ключевое отличие**: Значение `2` при фильтрации означает **"ОТ 1B и выше"**, то есть фильтрация работает как `>= 1`.

### Как работает фильтрация при поиске?

При фильтрации анкет используется условие **"ОТ"** (больше или равно):

**Пример:**
- Если пользователь при создании анкеты выбрал **"От 1B"** (сохранится 2), то при поиске он найдётся по фильтру **">= 1"**
- Если пользователь при поиске выбирает **"От 4В"** (фильтр 4), найдутся анкеты с `requirements_hydra >= 4`

### Валидные значения для хранения в БД

**Для всех полей (hydra, himera, lkv):**
```python
valid_values = [1, 2, 4, 8, 12, 16, 20, 24]
```

Обработчик будет отклонять любые другие значения с ошибкой "Некорректное значение!"

## Быстрый старт (локально)

1. Создать и активировать виртуальное окружение:

```powershell
python -m venv venv
& venv\Scripts\Activate.ps1
```

2. Установить зависимости:


3. Настроить переменные окружения (токен бота, DATABASE_URL) в `config.py` или в `.env` (если используете загрузчик окружения).

5. Запустить бота:

```powershell

```

## Модель `Player` (ключевые поля)

Поля, важные для поиска и фильтрации:

- `id` — PK
- `user_id` — владелец анкеты

### Как обрабатывается выбор в клавиатуре

- Каждая кнопка имеет `callback_data` вида `hydra_<value>` (пример: `hydra_4`).
- В обработчике значение извлекается как `data = callback.data.split("_")[-1]` и приводится к `int`.
- Значения валидируются по списку допустимых значений (см. раздел "Валидные значения").

## Нюанс фильтрации: значение 2 (От 1B)

- При выборе кнопки "От 1B" сохраняется `2` в поле `requirements_hydra`.
- При поиске/фильтрации это значение трактуется как `>= 1` (то есть показывать анкеты с 1 и выше).
- Пример SQLAlchemy-запроса для поиска игроков по гидре >= 1:

```python
from sqlalchemy import select
from src.player.models import Player

stmt = select(Player).where(Player.requirements_hydra >= 1)
```

Если вы хотите найти анкеты, у которых требование гидры именно "От 1B" (значение 2), используйте `== 2`.

## Список валидных значений (для hydra/himera)

```python
valid_values = [1, 2, 4, 8, 12, 16, 20, 24, 28]
```

## Как добавить новую кнопку/значение

1. Добавить кнопку в `src/player/keyboards.py`, указав `callback_data` в формате `hydra_<value>`.
2. Добавить значение в проверку валидности в обработчиках (`create.py` и `update.py`).
3. При необходимости — обновить код фильтрации в месте поиска/репозитория.
