# ПЧУГЛ Бот

Простой Telegram-бот на `aiogram` для управления игровыми анкетами игроков и кланов.

## О проекте

Проект позволяет:
- регистрировать анкеты игрока или клана;
- просматривать и редактировать собственные анкеты;
- публиковать анкеты в общий поиск;
- искать подходящих игроков и кланы;
- оставлять отзывы и выставлять рейтинг.

## Установка зависимостей

1. Создайте виртуальное окружение:
```powershell
python -m venv venv
```
2. Активируйте его:
```powershell
venv\Scripts\Activate.ps1
```
3. Установите зависимости:
```powershell
pip install -r requirements.txt
```

## Запуск проекта

```powershell
python -m src.bot
```

> Убедитесь, что в проекте настроены токен бота и параметры базы данных перед запуском.
